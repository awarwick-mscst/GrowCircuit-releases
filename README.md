# GrowCircuit releases

Installers for GrowCircuit, a local-first grow room monitor for Windows.

Download the latest `.msi` from [Releases](../../releases). GrowCircuit checks
here for updates once a day and tells you when a new version is out.

These builds are not code-signed yet, so Windows will say the publisher is
unknown — choose **More info**, then **Run anyway**. Each release carries a
SHA-256 file so you can confirm what you downloaded.

The source is not in this repository.
